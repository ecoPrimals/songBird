# songbird-primal-coordination

Inter-primal coordination primitives for sovereign mesh networks.

## Overview

This crate provides the foundational types and patterns for coordinating between different primals in the ecoPrimals ecosystem, maintaining sovereignty and capability-based discovery principles.

## Features

- Coordination pattern types
- Inter-primal message passing
- Capability-based routing
- Sovereignty-preserving protocols
