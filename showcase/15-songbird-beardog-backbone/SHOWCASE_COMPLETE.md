## 🧬 Core Concepts Demonstrated

### **1. Genetic Network Model**

```
Genesis Ceremony → Lineage Chain → Family Trust
     (A→B)            [B, A, ...]      (Relay Duty)
```

**Key Insight:** Lineage replaces infrastructure.

### **2. BirdSong Protocol**

```
Broadcast (encrypted) → Family Decrypts → Strangers See Noise
```

**Key Insight:** Privacy by cryptographic design.

### **3. Lineage Relay**

```
C (behind NAT) → B (ancestor relay) → A (destination)
```

**Key Insight:** No TURN servers needed.

### **4. Zero Hardcoding**

```
Capability Discovery → Dynamic Connection → No Primal Names
```

**Key Insight:** Infant discovery at runtime.

## 📊 Demonstration Flow

### **Demo 1: Genesis Ceremony** (01-genesis-ceremony.sh)

**Duration:** 2-3 minutes  
**Shows:**
1. Songbird orchestrates ceremony
2. BLE proximity verification
3. BearDog generates keys
4. Witness network coordination
5. BearDog signs lineage
6. Final identity construction

**Result:** Node B born as descendant of Node A

### **Demo 2: BirdSong Broadcasting** (02-birdsong-broadcast.sh)

**Duration:** 2-3 minutes  
**Shows:**
1. Node C behind NAT needs connectivity
2. BearDog encrypts BirdSong for ancestors
3. Songbird broadcasts message
4. Family nodes (B, A) decrypt successfully
5. Stranger node (X) sees only noise

**Result:** Privacy-preserving discovery demonstrated

### **Demo 3: Lineage Relay** (03-lineage-relay.sh)

**Duration:** 3-4 minutes  
**Shows:**
1. BearDog authorizes relay based on lineage
2. Masking level determined (SubMasked)
3. Relay offer sent by Node B
4. Songbird establishes relay session
5. Traffic flows: C → B → A
6. Relay sees metadata only, not content

**Result:** NAT traversal without TURN servers

### **Demo 4: Multi-Primal Coordination** (04-multi-primal.sh)

**Duration:** 4-5 minutes  
**Shows:**
1. Squirrel (AI) needs storage and compute
2. Discovery via BirdSong (no hardcoding)
3. NestGate and Toadstool respond
4. Multiple connections (relay + direct)
5. AI pipeline: Get data → Process → Store results
6. Clean separation of concerns

**Result:** Ecosystem working together

### **Demo 5: Hardware Root of Trust** (05-hardware-genesis.sh)

**Duration:** 3-4 minutes  
**Shows:**
1. SoloKey hardware detection
2. BearDog hardware attestation
3. Key derivation from hardware PRNG
4. Genesis with hardware-backed keys
5. Security benefits explained

**Result:** Tamper-resistant identity

### **Demo 6: Full Integration Test** (06-full-integration.sh)

**Duration:** 5-7 minutes  
**Shows:**
1. 3-node network (A → B → C)
2. 10 automated tests
3. Genesis, BirdSong, relay, privacy
4. Multi-primal coordination
5. Zero hardcoding verification
6. Complete success criteria

**Result:** All systems verified end-to-end
