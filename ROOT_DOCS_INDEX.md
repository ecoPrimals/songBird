## 📌 IMPORTANT NOTES

### Ecosystem Protocols
⚠️ **The ecoPrimals ecosystem uses `tarpc` and `JSON-RPC`** (NOT gRPC)
- See SESSION2_COMPLETE_JAN_13_2026.md for gRPC removal work
- All RPC references should be tarpc or JSON-RPC

### Code Quality Standards
- **Max file size**: 1000 lines
- **Test coverage target**: 90%+ (currently ~80%)
- **Linting**: Must pass `cargo clippy --all-targets --all-features`
- **Formatting**: Must pass `cargo fmt --check`

### Architecture Principles
- **Zero hardcoding**: Primals discover each other at runtime
- **Capability-based**: Discovery based on advertised capabilities
- **Primal self-knowledge**: Each primal knows only itself
- **Genetic lineage**: Trust based on cryptographic ancestry
