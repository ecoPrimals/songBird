## 📝 Document Conventions

### File Naming

- `UPPERCASE_SNAKE_CASE.md` - Root-level important docs
- `lowercase-kebab-case.md` - Supporting/utility docs
- `SESSION_N_*.md` - Session reports (in sessions/)
- `*_COMPLETE.md` - Completed implementation reports

### Content Structure

All major documents should include:
- **Status**: Current state (✅ Complete, 🔄 In Progress, ⚠️ Needs Review)
- **Date**: When document was created/updated
- **Version**: Software version if applicable
- **Related Docs**: Links to other relevant documentation
