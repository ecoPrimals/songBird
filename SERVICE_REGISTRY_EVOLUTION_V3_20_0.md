## 🎯 Service Registry Use Cases

### Use Case 1: Primal Registration (Startup)
```rust
// BearDog starts up
let songbird = SongbirdClient::discover("nat0").await?;
songbird.register_service(ServiceInfo {
    primal_name: "BearDog",
    capabilities: vec!["encryption", "identity", "trust"],
    endpoint: "/run/user/1000/beardog-nat0.sock",
    protocol: "json-rpc",
    health_check_interval: 30,
}).await?;

// Songbird now knows: BearDog provides encryption at that socket
```

### Use Case 2: Capability Discovery (Runtime)
```rust
// biomeOS needs encryption
let songbird = SongbirdClient::discover("nat0").await?;
let primals = songbird.discover_by_capability("encryption").await?;
// Returns: [PrimalEndpoint { socket: "/run/user/1000/beardog-nat0.sock", ... }]

// Connect directly to BearDog
let beardog = BearDogClient::connect(&primals[0].endpoint).await?;
```

### Use Case 3: Health Monitoring (Visualization)
```rust
// petalTongue visualizes ecosystem
let songbird = SongbirdClient::discover("nat0").await?;
let all_primals = songbird.discover_by_capability("*").await?; // All primals

for primal in all_primals {
    let health = songbird.get_service_health(&primal.service_id).await?;
    // Render node: green (healthy), yellow (degraded), red (down)
}
```

### Use Case 4: Health Check (Self)
```rust
// Check if Songbird itself is healthy
let health = songbird.health_check().await?;
assert_eq!(health.status, "healthy");
```

## 🎯 Socket Path Evolution

### Current (v3.19.3)
```bash
/tmp/songbird-{node_id}.sock
# Example: /tmp/songbird-tower-001.sock
```

**Problem**: Doesn't match biomeOS expectation

### Required (v3.20.0)
```bash
/run/user/{uid}/songbird-{family_id}.sock
# Example: /run/user/1000/songbird-nat0.sock
```

**Solution**:
```rust
fn socket_path_for_family(family_id: &str) -> PathBuf {
    let uid = unsafe { libc::getuid() };
    PathBuf::from(format!("/run/user/{}/songbird-{}.sock", uid, family_id))
}
```

**Discovery**:
```rust
// biomeOS discovers by:
let family_id = std::env::var("SONGBIRD_FAMILY_ID").unwrap_or("default");
let socket = format!("/run/user/{}/songbird-{}.sock", get_uid(), family_id);
```

## 🏗️ Service Registry Architecture

### Internal Storage
```rust
pub struct RegisteredService {
    service_id: String,            // Auto-generated UUID
    primal_name: String,           // "BearDog"
    capabilities: Vec<String>,     // ["encryption", "identity"]
    endpoint: String,              // "/run/user/1000/beardog-nat0.sock"
    protocol: String,              // "json-rpc"
    registered_at: SystemTime,     // When registered
    last_health_check: SystemTime, // Last health probe
    health_status: String,         // "healthy" | "degraded" | "down"
}

pub struct ServiceRegistry {
    services: Arc<RwLock<HashMap<String, RegisteredService>>>,
}
```

### Lifecycle
```text
1. Primal starts → Discovers Songbird socket
2. Primal calls register_service()
3. Songbird stores in HashMap, generates service_id
4. Other primals call discover_by_capability()
5. Songbird returns matching services from HashMap
6. Periodic health checks update health_status
```
