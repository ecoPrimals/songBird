```
                       │
        ┌──────────────┼──────────────┐
        │              │              │
        ▼              ▼              ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │ BearDog  │  │ Squirrel │  │   ...    │
  │ (Crypto) │  │ (Funds)  │  │  (Any)   │
  └──────────┘  └──────────┘  └──────────┘
```

### **Universal IPC** (v4.0.0)
```
┌─────────────────────────────────────────────────┐
│         Application Primals                     │
│  (BearDog, Squirrel, etc.)                      │
└─────────────────────────────────────────────────┘
                       │
                       │ Universal API
                       │ (platform-agnostic)
                       ▼
┌─────────────────────────────────────────────────┐
│      songbird-universal-ipc                     │
│  - Capability Discovery                         │
│  - Service Registry                             │
│  - Platform Abstraction                         │
└─────────────────────────────────────────────────┘
                       │
        ┌──────────────┼──────────────┐
        │              │              │
        ▼              ▼              ▼
  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │   Unix   │  │   TCP    │  │ Windows  │
  │ Sockets  │  │ Fallback │  │  Pipes   │
  └──────────┘  └──────────┘  └──────────┘
```

### **Crate Organization**
- `songbird-orchestrator` - Main binary + orchestration logic
- `songbird-universal-ipc` - **NEW** Universal IPC (v4.0.0)
- `songbird-tls` - Pure Rust TLS 1.3 implementation
- `songbird-discovery` - Service discovery (mDNS, DHT)
- `songbird-network-federation` - Federation management
- `songbird-genesis` - Physical channel management
- `songbird-primal-sdk` - SDK for primal integration
- `songbird-bluetooth` - Bluetooth discovery (optional)
- `songbird-canonical` - Canonical naming system
- `songbird-universal` - Shared types and utilities
- `songbird-test-utils` - Testing utilities (dev-only)

## 🎯 Use Cases

### **1. Service Discovery**
Automatically discover and connect to primals based on capabilities:

```rust
use songbird_universal_ipc::capability;

// Discover by capability (no hardcoding!)
let provider = capability::discover("crypto").await?;
let stream = ipc::connect(&provider.virtual_endpoint).await?;
```

### **2. Network Orchestration**
Manage connections and trust relationships:

```rust
// Establish trust-based connection
let connection = manager.establish_connection(
    peer_id,
    TrustLevel::CapabilityVerified,
    vec!["orchestration"],
).await?;
```

```rust
// Check availability
let report = checker.check_availability(&graph).await?;

let suggestions = checker.suggest_alternatives(&node).await?;
```
