## 🎯 **MIGRATION PATTERNS - COMPLETE CATALOG**

All 50 usages migrated using these proven patterns:

### **1. Struct Field Removal** (15+ structs)
```rust
// BEFORE
struct Client {
    http_client: reqwest::Client,
    config: Config,
}

// AFTER
struct Client {
    config: Config,
    // IpcHttpClient created per-request
}
```

### **2. Per-Request Client Creation** (15+ implementations)
```rust
async fn get_client(&self) -> Result<IpcHttpClient, Error> {
    IpcHttpClient::builder()
        .timeout(self.config.timeout)
        .build()
        .await
        .map_err(|e| Error::network(format!("Client error: {}", e)))
}
```

### **3. HTTP Method Updates** (30+ call sites)
```rust
// BEFORE
let response = self.http_client.get(&url).send().await?;

// AFTER
let client = self.get_client().await?;
let response = client.get(&url).await?;
```

### **4. Status Checks** (20+ checks)
```rust
// BEFORE
if response.status().is_success() { }

// AFTER
if response.is_success() { }
```

### **5. POST Requests** (10+ requests)
```rust
// BEFORE
client.post(&url).json(&payload).send().await?

// AFTER
client.post(&url).await.json(&payload)?.send().await?
```

### **6. Response Type Updates** (5+ signatures)
```rust
// BEFORE
async fn parse(response: reqwest::Response) -> Result<T>

// AFTER
async fn parse(response: songbird_http_client::Response) -> Result<T>
```

### **7. Connection Pools** (3+ pools)
```rust
// BEFORE
Vec<reqwest::Client>

// AFTER
Vec<Arc<IpcHttpClient>>
```
