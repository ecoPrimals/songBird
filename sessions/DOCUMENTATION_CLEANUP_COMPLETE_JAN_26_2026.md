## 🔄 Maintenance Process

### When to Archive

Archive documentation when:
- Implementation is 100% complete
- Document is purely historical
- Replaced by newer/better documentation
- No longer needed for active development

### When to Keep in Root

Keep documentation when:
- Actively being worked on
- Needed for current development
- Required for onboarding
- Essential reference material

### Update Procedures

**Always update**:
- STATUS.md - After any significant achievement
- CHANGELOG.md - For all user-facing changes
- ROADMAP.md - When priorities change

**Update as needed**:
- ROOT_DOCS_INDEX.md - When major docs added/removed
- Session reports - After each major work session
- Verification reports - After test coverage changes
