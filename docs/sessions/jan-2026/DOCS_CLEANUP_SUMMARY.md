## 📊 ORGANIZATION PRINCIPLES

### Root Level Criteria
Files at root must be:
1. **Essential** - Frequently accessed
2. **Current** - Active or recent (not historical)
3. **Quick** - Summary/overview level
4. **Navigational** - Help users find deeper docs

### Archive Criteria
Files in `docs/sessions/` are:
1. **Detailed** - Comprehensive technical docs
2. **Historical** - Session-specific records
3. **Reference** - Deep-dive material
4. **Organized** - By date/session

### Naming Convention
- **Root**: Descriptive names (e.g., `README_AUDIT_FINDINGS.md`)
- **Archives**: Date-stamped (e.g., `COMPREHENSIVE_AUDIT_JAN_14_2026.md`)
- **Sessions**: Grouped by month (e.g., `docs/sessions/jan-2026/`)
