## 🎯 Core Principles

### 1. Each Primal Only Knows Itself ✅
- Zero hardcoded primal names
- Runtime discovery via environment variables
- Capability-based, not identity-based

### 2. Complete Implementations Only ✅
- No production mocks
- Clear errors when features unavailable
- Graceful degradation with explicit communication

### 3. Modern Idiomatic Rust ✅
- Latest stable features
- Async/await throughout
- Type-driven development

### 4. Fast AND Safe ✅
- Not "fast OR safe" - both!
- Zero unnecessary unsafe
- Performance with safety

### 5. Zero Hardcoding ✅
- No primal names in code
- No vendor dependencies
- Environment-driven configuration
