## Configuration Changes

### New Environment Variables

```bash
# TLS Configuration
SONGBIRD_TLS_ENABLED=false          # Enable HTTPS (default: false)
SONGBIRD_TLS_CERT=certs/songbird.crt  # Certificate path
SONGBIRD_TLS_KEY=certs/songbird.key   # Private key path
SONGBIRD_TLS_SANS=localhost,127.0.0.1 # Subject Alternative Names
SONGBIRD_NODE_ID=songbird            # Common name for cert
```

- HTTP server: Remains default (no breaking changes)
- TLS: Opt-in via environment variable

## Migration Guide

### For Existing Deployments

**No migration needed** ✅

Everything works exactly as before:

```bash
# Existing deployment (unchanged)

# Still starts HTTP server on default port
```

### To Enable TLS

**Simple opt-in:**

```bash

cargo run --release --bin songbird-orchestrator

# Generates self-signed cert automatically
# Starts HTTPS server
```
