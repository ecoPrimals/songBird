### Real-time Metrics

```bash
./scripts/unification_metrics.sh

# Compare to baseline
./scripts/unification_metrics.sh --compare reports/baseline_metrics_nov_9_2025.json

# Export to JSON
./scripts/unification_metrics.sh --json > metrics.json
```
