## 💡 ARCHITECTURAL HIGHLIGHTS

### **Service-Based IPC** (TRUE PRIMAL)

**Before** (Library-Based) ❌:
```rust
// Other primals
use songbird_universal_ipc::ipc;  // ❌ Code embedding!

let endpoint = ipc::register("myprimal", caps).await?;
let stream = ipc::connect("/primal/other").await?;
```

**After** (Service-Based) ✅:
```rust
// Other primals
use tokio::net::UnixStream;  // ✅ Standard library!

// Connect to Songbird service
let songbird = UnixStream::connect("/primal/songbird").await?;

// JSON-RPC call
let request = json!({
    "jsonrpc": "2.0",
    "method": "ipc.register",
    "params": { "primal_id": "myprimal", ... },
    "id": 1
});

songbird.write_json(&request).await?;
let response = songbird.read_json().await?;
```

**Result**: ✅ **TRUE PRIMAL autonomy preserved!**

// No hardcoded primal names!
let providers = discover_by_capability("crypto").await?;
