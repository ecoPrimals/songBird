## REGRESSION PROTECTION

### The Bug We Fixed
**Before:**
- Discovery broadcasts configured port (8080)
- Server listens on fallback port (8082)
- Other towers try to connect to 8080 → FAIL
- Result: Silent connection failures

**After:**
- Discovery broadcasts actual port (8082)
- Server listens on actual port (8082)
- Other towers connect to 8082 → SUCCESS
- Result: Robust federation
